# 💰 Budget Split Calculator

A simple and responsive **Budget Split Calculator** that allows users to divide expenses among multiple people instantly. It is useful for splitting bills during trips, parties, restaurants, hostel expenses, or shared living.

## ✨ Features

- 💵 Enter the total budget or bill amount
- 👥 Split expenses among multiple people
- 🧮 Automatic per-person calculation
- ⚡ Instant results without page reload
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

```
Budget-Split-Calculator/
│── index.html
│── style.css
│── script.js
│── README.md
```

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Double-click **index.html** or open it in any web browser.
4. Enter the total amount and number of people.
5. View the calculated amount per person instantly.
